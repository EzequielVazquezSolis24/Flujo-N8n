🧠 ¿Qué es Open Interpreter y por qué lo usamos?

Open Interpreter es la versión open source de Claude Code. Le das instrucciones en lenguaje natural y él ejecuta código, edita archivos, instala cosas, navega la web y hace casi todo lo que haría Claude Code — pero conectado a la API que vos elijas.

🔵 Claude Code

  • Oficial de Anthropic
  • Requiere suscripción Pro ($20/mes) o créditos de API
  • Solo usa modelos de Claude
  • Muy pulido y estable

🟢 Open Interpreter + Groq ← ESTA OPCIÓN

  • Open source, gratis
  • Groq tiene free tier generoso
  • Soporta Groq, Gemini, DeepSeek, OpenRouter
  • Hace lo mismo: ejecuta en tu PC

¿Qué puede hacer en tu computadora?

  • Ejecutar comandos de terminal
  • Crear, editar y borrar archivos
  • Instalar paquetes y programas
  • Correr scripts de Python, Node, etc.
  • Navegar la web y extraer información
  • Trabajar con imágenes y PDFs
  • Controlar tu flujo de n8n via API

📋 Plan paso a paso

1

Obtener API Key de Groq (gratis)

  1. Ir a console.groq.com
  2. Crear cuenta (puede ser con Google)
  3. Ir a API Keys → Create API Key
  4. Copiar y guardar la key — empieza con gsk_...
✅ No pide tarjeta de crédito. Es gratis directamente.
2

Verificar que tenés Python instalado

Abrir la terminal y correr:

python --version
# Necesitás Python 3.10 o superior
# Si no lo tenés: python.org → Download
3

Instalar Open Interpreter

# En la terminal:
pip install open-interpreter
⚠️ Si da error de permisos, usar: pip install open-interpreter --user
4

Configurar con Groq y correr por primera vez

# Opción A: directo desde terminal (reemplaza TU_KEY con tu API key)
interpreter --api_base https://api.groq.com/openai/v1 \
            --api_key TU_KEY_DE_GROQ \
            --model groq/llama-3.3-70b-versatile
# Opción B: con variable de entorno (más cómodo)

# En Linux/Mac, agregar al .bashrc o .zshrc:
export GROQ_API_KEY="TU_KEY_DE_GROQ"

# Luego correr simplemente:
interpreter --api_base https://api.groq.com/openai/v1 \
            --model groq/llama-3.3-70b-versatile
✅ Si ves el prompt > aparecer, ya está funcionando.
5

Crear archivo de configuración permanente (recomendado)

Para no tener que escribir los flags cada vez, crear el archivo de config:

# Ruta del archivo:
# Linux/Mac: ~/.config/open-interpreter/config.yaml
# Windows:   C:\Users\TU_USUARIO\.config\open-interpreter\config.yaml

Contenido del archivo config.yaml:

model: groq/llama-3.3-70b-versatile
api_base: https://api.groq.com/openai/v1
api_key: TU_KEY_DE_GROQ
# Opcional: confirmar antes de ejecutar comandos
safe_mode: ask
# Opcional: idioma español
system_message: "Responde siempre en español."

Con eso, para iniciar solo necesitás escribir:

interpreter
6

Primera prueba — verificar que funciona

Una vez en el prompt >, escribir:

"Creá un archivo llamado prueba.txt en el escritorio con el texto Hola mundo"

Si lo crea, todo está funcionando correctamente.

🔌 Alternativa: Cline en VS Code

Si preferís trabajar desde VS Code en lugar de la terminal:

1

Instalar Cline

  1. Abrir VS Code
  2. Extensions (Ctrl+Shift+X)
  3. Buscar "Cline" e instalar
2

Configurar con Groq

  1. Click en el ícono de Cline en la barra lateral
  2. Settings → API Provider → seleccionar OpenAI Compatible
  3. Base URL: https://api.groq.com/openai/v1
  4. API Key: tu key de Groq
  5. Model: llama-3.3-70b-versatile

ErrorCausaSolución

Rate limit exceeded Llegaste al límite de Groq Esperar o cambiar a Gemini API temporalmente
Se congela sin responder El modelo está procesando Esperar 10-15 segundos, Groq es muy rápido normalmente

📋 Pasos de instalación

1

Obtener API Key de Gemini 2.5 Pro (gratis)

  1. Ir a aistudio.google.com
  2. Iniciar sesión con Google
  3. Click en "Get API Key" → "Create API key"
  4. Copiar la key — empieza con AIza...
✅ Gratis: 1.500 requests/día. Sin tarjeta de crédito.
2

Crear el Bot de Telegram

  1. Abrir Telegram y buscar @BotFather
  2. Escribir /newbot
  3. Poner nombre: Mi PC IA (o el que quieras)
  4. Poner username: algo como mipcia_bot
  5. BotFather te da el token — guardarlo, empieza con números y tiene : en el medio
💡 Ese token es la contraseña de tu bot. No lo compartas.
3

Obtener tu Telegram User ID

  1. Buscar en Telegram: @userinfobot
  2. Escribirle cualquier mensaje
  3. Te responde con tu ID — es un número como 123456789
  4. Guardar ese número — es tu ID de seguridad
⚠️ Este ID es importante: solo vos vas a poder controlar el bot.
4

Instalar dependencias

En la terminal, dentro de la carpeta entorno-local/:

# Instalar todo de una vez
pip install -r requirements.txt

O manualmente:

pip install open-interpreter python-telegram-bot python-dotenv Pillow
⚠️ Si open-interpreter tarda, es normal. Pesa bastante.
5

Configurar el archivo .env

  1. Copiar el archivo .env.example y renombrarlo a .env
  2. Completar las 3 variables con tus datos:
TELEGRAM_BOT_TOKEN=tu_token_del_bot
TELEGRAM_USER_ID=tu_id_de_telegram
GEMINI_API_KEY=tu_api_key_AIza...
6

Correr el bot

# En la terminal, dentro de entorno-local/
python telegram-bot.py

Deberías ver:

🤖 Bot iniciado. Esperando mensajes de Telegram...
✅ Gemini 2.5 Pro conectado
✅ OS Mode habilitado
7

Primera prueba desde Telegram

  1. Abrir el bot en Telegram
  2. Escribir /start — debe responder
  3. Escribir: "Creá un archivo llamado prueba.txt en el escritorio"
  4. Verificar que el archivo apareció en tu PC
✅ Si funciona, ya tenés control total de tu PC desde el celular.

📱 Comandos del Bot

  • /start — Activa el bot y muestra bienvenida
  • /status — Muestra si todo está funcionando
  • /screenshot — Te manda una foto de tu pantalla actual
  • /reset — Limpia el historial de conversación del intérprete
  • /stop — Detiene la tarea que está ejecutando
  • Cualquier texto — Open Interpreter lo ejecuta en tu PC

🔄 Dejar el bot corriendo siempre (automático)

Para que el bot arranque solo cuando prendés la PC:

En Windows — Tarea programada

# En PowerShell como administrador:
$action = New-ScheduledTaskAction -Execute "python" -Argument "C:\ruta\entorno-local\telegram-bot.py"
$trigger = New-ScheduledTaskTrigger -AtLogOn
Register-ScheduledTask -TaskName "BotIA" -Action $action -Trigger $trigger

En Linux/Mac — systemd o PM2

# Con PM2 (más simple):
npm install -g pm2
pm2 start telegram-bot.py --interpreter python
pm2 startup  # para que arranque solo
pm2 save

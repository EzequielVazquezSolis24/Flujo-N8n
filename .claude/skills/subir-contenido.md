---
description: Guía el proceso completo de subir contenido generado por IA a Instagram y TikTok. Ayuda a preparar la imagen o video, el caption, los hashtags y coordina la publicación.
---

1. Pregunta qué contenido hay listo para subir:
   - ¿Es imagen o video?
   - ¿Dónde está guardado el archivo?
   - ¿Tiene caption y hashtags o hay que generarlos?

2. Si falta el caption, lee el PDF de tendencias del día y genera uno optimizado para engagement con:
   - Hook en la primera línea (primeras palabras que enganchen)
   - Cuerpo corto y directo
   - Call to action sutil
   - 20-25 hashtags mixtos (populares + nicho)

3. Verifica el formato del archivo:
   - Instagram feed: JPG/PNG mínimo 1080x1080, o 1080x1350 (4:5)
   - Reels/TikTok: MP4, relación 9:16, mínimo 1080x1920
   - Si no cumple, usa ffmpeg o PIL para convertirlo

4. Para la publicación:
   - Si hay API de Instagram configurada: sube automáticamente
   - Si no: abre el navegador, va a Instagram, guía el proceso manual paso a paso

5. Sugiere el mejor horario si no se va a publicar ahora
6. Registra en un log local la publicación con fecha, hora y tipo de contenido

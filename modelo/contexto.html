💡 2. Idea del Proyecto - Modelo de Instagram creada por IA

El objetivo es crear y gestionar una cuenta de Instagram de una modelo generada por IA, con contenido automatizado diariamente basado en tendencias reales de redes sociales.

⚙️ 3. Flujo n8n - Parte 1 (Implementado)

Archivo: flujo-tendencias-instagram.json

#NodoFunción
1Trigger Diario 8amDispara el flujo todos los días a las 8:00am (cron: 0 8 * * *)
2Perplexity - Investigar TendenciasInvestiga tendencias virales del día en Instagram y TikTok usando el modelo sonar-pro
3Extraer Respuesta PerplexityProcesa y limpia la respuesta, agrega la fecha del día
4DeepSeek - Análisis y BriefAnaliza las tendencias y genera brief creativo con descripción visual + prompt de IA usando deepseek-chat
5Extraer Respuesta DeepSeekProcesa la respuesta y combina con datos de Perplexity
6Generar HTML para PDFCrea un HTML estilizado con el reporte completo del día
7Convertir a PDFConvierte el HTML a PDF via html2pdf.app API
8Pasar PDF con FechaPasa el binario PDF al siguiente paso con la fecha
9Subir a Google DriveSube tendencias_FECHA.pdf a la carpeta configurada de Drive
10Guardar en EscritorioGuarda copia local del PDF en el escritorio de la PC

DeepSeek genera en cada brief:

  • Resumen ejecutivo de las 3 tendencias más importantes del día
  • Tipo de contenido recomendado: VIDEO o IMAGEN (con justificación)
  • Descripción visual detallada (pose, iluminación, ropa, colores, filtros)
  • Caption completo con emojis y hashtags listos para publicar
  • Horario óptimo de publicación
  • Prompt listo para generadores de IA (Midjourney, Runway, etc.)

📥 5. Cómo importar el flujo en n8n

Descargar el repositorio

git clone https://github.com/ezequielvazquezsolis24/flujo-n8n.git
cd flujo-n8n
git checkout claude/document-skills-mxkVM

Importar en n8n

  1. Abrir n8n en el navegador (http://localhost:5678)
  2. Ir a Workflows → botón "+" → "Import from file"
  3. Seleccionar el archivo flujo-tendencias-instagram.json
  4. Reemplazar los 4 placeholders de API keys
  5. Conectar credenciales de Google Drive
  6. Ajustar la ruta del escritorio según tu sistema:
SistemaRuta del escritorio
Linux/home/TU_USUARIO/Desktop/tendencias_{{ fecha }}.pdf
Mac/Users/TU_USUARIO/Desktop/tendencias_{{ fecha }}.pdf
WindowsC:\Users\TU_USUARIO\Desktop\tendencias_{{ fecha }}.pdf
  1. Activar el flujo con el toggle de Active
  2. Hacer clic en "Test workflow" para verificar que funciona
